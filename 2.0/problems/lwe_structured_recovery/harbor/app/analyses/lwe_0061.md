## Bound public record

This instance has `(n,m,q)=(49,147,2053)`. Each `sparse_uniform` matrix row
has exactly 14 distinct supported coordinates and an independent nonzero
coefficient in `{1,...,2052}` at each. The secret is uniform in
`(Z/2053Z)^49`, and the public predicate admits every such vector. The
`sparse_bounded` error has exactly nine nonzeros in
`[-256,-1] union [1,256]`; validation caps are `max_abs=256`, `L1<=2,304`,
`L2^2<=589,824`, and support at most nine.

The expanded matrix and its first 49 rows both have rank `49/49` modulo 2053.
All 147 rows and all 147 supports are distinct. These exact seed facts exclude
an elementary repeated-support route, but do not imply that every selected
clean 49-row minor is nonsingular.

## Selected clean-subset median model

Sample 49 rows, solve `A_I s=b_I (mod q)`, and validate against all 147 rows.
The recorded formula is `ln(2)/(p*max(100*(16/n)^1.5,5))`. There are 138
planted-clean rows, so the exact clean-subset probability is

`p = C(147-9,49)/C(147,49) = C(138,49)/C(147,49) = 0.022871158533120026`.

The `analytical-clean-subset-v2` model uses
`ln(2)/p = 30.306605568589355` median attempts. SA_Q's
family rate is `max(100*(16/49)^1.5,5) = 18.65889212827988`
systems/second, giving `1.624244642191586` seconds. This prediction belongs to
`E0=[1,4)` and is close to the 1.624505-second target.

The hypergeometric `p` is exact conditional on the planted nine-row support;
the rest is modeling. `ln(2)/p` is a continuous independent-trial proxy, and
the rate is not a measurement. Rank failures of clean minors, subset reuse,
and validation overhead are not separately charged. Full rank of the whole
matrix and one square prefix is insufficient to remove those uncertainties.

## Literature route and final-byte calibration

This is a clean-room adaptation of the error-free-subset, linear-solve, and
retry route in [Sun--Tibouchi--Abe, ePrint 2020/666,
Section 4.2](https://eprint.iacr.org/2020/666). The exact fixed-support event
for this record is `C(m-w,n)/C(m,n) = C(138,49)/C(147,49)`. In particular,
the paper's uniform-matrix rank calculation and asymptotic runtime are not
transferred to this sparse finite matrix; clean-minor rank and throughput stay
instance-specific uncertainties.

The final-byte campaign in [`CALIBRATION.md`](../CALIBRATION.md) records a
successful `bounded_error` recovery with seed 0 in 1.737373 internal seconds;
the recovered vector passed the public verifier. That bounded run is evidence
for the released E0 point, but the metadata deliberately stays
`calibration_status="extrapolated"` and `measured_runtime_seconds=null`
because the campaign is not a complete E0--E5 benchmark.

## Structure, alternatives, and boundary

The secret is already unrestricted q-ary, so there is no small-secret domain
for this attack to exploit: a clean field solve recovers it directly. The
model uses error support but treats the 14-sparse row graph as ordinary linear
algebra. Sparse elimination constants, graph/error-support interaction, the
98-dimensional left-kernel syndrome problem, and specialized sparse-matrix
methods can all change the practical crossover.

The repository-level smoke screen ran `primal_bdd` with a two-second cap and
recovered no witness. This capped non-recovery is only smoke evidence; it does
not estimate primal cost or rank it against the 1.624-second model. That model
is neither a demonstrated portfolio minimum nor a lower bound. Here
`14/sqrt(49)=2`, a value bounded away from zero; equivalently, the row weight
is `Theta(sqrt(n))` rather than `o(sqrt(n))`. The cited sparse-LWE lower-bound premise is not
instantiated. Calibration is `extrapolated`, measured runtime is null, and no
hardness claim is made.
