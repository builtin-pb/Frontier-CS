This is a clean-room adaptation of the error-free-subset, linear-solve, and
retry route in [Sun--Tibouchi--Abe, ePrint 2020/666,
Section 4.2](https://eprint.iacr.org/2020/666). This exact-weight record uses

uniform-matrix rank argument and asymptotic runtime are not transferred to the

uncertainties.

## Structure, alternatives, and boundary

The selected attack solves directly for `s` over `F_769`; it does not exploit
the `2^104` binary domain except in final validation. Binary enumeration and
hybrid guessing are therefore separate upper bounds, and the simultaneous
small secret plus sparse error admits interaction attacks not priced by this
single-structure model. The error bound changes residual filters and syndrome
decoding, although it leaves `p` unchanged.

The repository-level smoke screen ran `primal_bdd` with a two-second cap and
recovered no witness. That capped non-recovery is only smoke evidence, not a
primal runtime estimate or a comparison with 629.308 seconds. The selected
number is not demonstrated to be the portfolio minimum and cannot serve as a
lower bound. Uniform `A` removes the
sparse-matrix question, but no Gaussian target-error mapping composes a
binary-secret or entropy-LWE theorem with this exact-support error. The status
is `extrapolated`, measured runtime is null, and no hardness claim is made.
